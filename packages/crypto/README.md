This package contains low-level cryptographic functionality used in other
@bkc-network-lib libraries. Little of it is implemented here, but mainly it is a
curation of external libraries along with correctness tests. We add type safety,
some more checks, and a simple API to these libraries. This can also be freely
imported outside of BKC based applications.
